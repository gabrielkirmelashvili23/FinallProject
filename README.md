კონსოლის პროგრამა სტუდენტების, კურსების, ჯგუფებისა და გადასახადების სამართავად. სამი როლია: ადმინი, ლექტორი და სტუდენტი. მონაცემები ინახება `Data` საქაღალდეში, ამიტომ პროგრამის დახურვისას არაფერი იკარგება. ინტერფეისი Spectre.Console-ითაა გაკეთებული, ენა: English, Qartuli, Русский.

## გაშვება

Visual Studio-ში გახსენი `FinallProj.slnx` (.NET 10) და დააჭირე F5.

## პირველი ნაბიჯები

1. მთავარ მენიუში აირჩიე `Register` -> `Admin`. კოდი: `ADMIN-2026`.
2. შედი ამ ადმინით და აირჩიე `Users and security` -> `Load starter data`. ეს ქმნის 3 კურსს, 4 ჯგუფს, ლექტორს, 6 სტუდენტს გადახდებით და ასევე სასწავლო მონაცემებს: ლექციებს, სიახლეებს, ქულებს, დავალებებს და გამოცდებს. სასწავლო მონაცემები ცალკეც იტვირთება: `Load academic starter data`.
3. საწყისი მომხმარებლები: `lecturer1` და `s101`-დან `s106`-მდე, პაროლი `Step@2026`.

## რას აკეთებს

- **რეგისტრაცია** სამივე როლისთვის: username-ის შემოწმება, პაროლის სიძლიერის ინდიკატორი, უსაფრთხოების კითხვა.
- **პაროლი**: შეცვლა ძველი პაროლით, აღდგენა უსაფრთხოების კითხვით, განულება ადმინის მიერ.
- **სტუდენტები**: დამატება, ყველას ნახვა, ძებნა სიის ნომრით ან სახელით, შეფასების განახლება (A-F), სტატისტიკა, წაშლა, report card.
- **კურსები და ჯგუფები**: კურსს აქვს საფასური და ყოველთვიური ნაწილები, ჯგუფს ადგილების რაოდენობა. სისტემა აჩვენებს, რამდენი სტუდენტია ჯგუფში და რამდენი ადგილია თავისუფალი.
- **ჩარიცხვა**: სტუდენტი ირჩევს ჯგუფს, ხედავს ხარჯების გადახედვას და მერე იქმნება გადახდის გეგმა.
- **გადახდები**: ყოველთვიური ნაწილები, ქვითარი ფაილად, ვადაგადაცილება, საკომისიო, დავალიანება, სტიპენდია.
- **ფინანსური პანელი** ადმინისთვის: ჯამები, დიაგრამები, შემოსავალი კურსების მიხედვით, მოვალეები, CSV ექსპორტი.
- **ეკრანები**: მისალმების პანელი, უნივერსიტეტის ხე (კურსი -> ჯგუფი -> სტუდენტი), გადახდების კალენდარი და პროგრესის ზოლი.
- **აუდიტის ჟურნალი**: შესვლა, რეგისტრაცია, გადახდა, პაროლისა და კოდების ცვლილება.
- **თარიღის სიმულაცია**: ადმინს შეუძლია თარიღის წინ გადაწევა, რომ ვადაგადაცილება და საკომისიო ვნახოს.
- **უკან დაბრუნება ყველგან**: ყველა სიის ბოლოში არის `უკან` ღილაკი, ხოლო ნებისმიერ ველში ტექსტის ნაცვლად `back` (ან `უკან`) ჩაწერით მოქმედება უქმდება და წინა მენიუში ბრუნდები.

### ლექციები

ლექციას აქვს თარიღი, დაწყების დრო, ხანგრძლივობა, საგანი, ლექტორი, ფორმატი (აუდიტორია ან ონლაინ ბმული) და სტატუსი (დაგეგმილი, ჩატარებული, გაუქმებული). შეიძლება ლექციის ყოველკვირეულად გამეორება. სისტემა ამოწმებს კონფლიქტებს: იმავე ჯგუფს, იმავე ლექტორს ან იმავე აუდიტორიას ერთსა და იმავე დროს ორი ლექცია ვერ ექნება (გაუქმებული ლექცია დროს ათავისუფლებს). წარსულში ლექციის დაგეგმვა და მომავალი ლექციის „ჩატარებულად“ მონიშვნა შეუძლებელია. სტუდენტი შესვლისთანავე ხედავს დღევანდელ ლექციებს დროის მიხედვით დალაგებულს, ახლო გამოცდის გაფრთხილებას და გაფრთხილებას, თუ ფინალში ჩარჩა.

### სიახლეები

სათაური, ტექსტი, კატეგორია (ზოგადი, ღონისძიებები, გამოცდები, ცხრილი, სტიპენდიები), თარიღი, ავტორი და მისი როლი. ახალი სიახლე ზემოთაა.

### ქულები და რეიტინგი

ლექტორს შეუძლია სტუდენტს ქულა ჩაუწეროს რამდენჯერაც სჭირდება (თითო ჩანაწერი -100-დან 100-მდე, ნულის გარეშე, მინუსი ქულის მოხსნას ნიშნავს). ყველა ჩანაწერი ისტორიაში რჩება: თარიღი, ქულა, მიზეზი და ვინ მისცა. შეიძლება მთელი ჯგუფისთვის ერთად ჩაწერაც. რეიტინგი ლაგდება ქულების ჯამით (კლებადობით ან ზრდადობით), სემესტრისთვის ან მთელი დროისთვის; ერთნაირი ქულა ერთ ადგილს იზიარებს (1, 2, 2, 4). დავალების შეფასებაც ქულებში ჯდება.

### დავალებები

ლექტორი ქმნის დავალებას (სათაური, აღწერა, ვადა, მაქსიმალური ქულა). სტუდენტი აგზავნის პასუხს ტექსტად, ბმულად ან ფაილად (მაქს. 5 MB, ფაილი ინახება `Data/Uploads`-ში). შემოწმებამდე შეუძლია ნამუშევრის ახალი ვერსიით ჩანაცვლება. ვადის შემდეგ 7 დღის განმავლობაში ჩაბარება შესაძლებელია, მაგრამ „დაგვიანებულად“ მოინიშნება; მერე ჩაბარება იხურება. ლექტორი წერს ქულას და კომენტარს (ორივე სავალდებულოა), სტუდენტი ხედავს და ქულა ავტომატურად ემატება მის ქულებს. ხელახალი შემოწმება ძველ ქულას ანაცვლებს და არ ამრავლებს.

### გამოცდები

გამოცდას აქვს თარიღი, დრო, აუდიტორია ან ბმული, დეტალები, მაქსიმალური ქულა და ტიპი (ჩვეულებრივი ან ფინალური). ჯგუფს სემესტრში მხოლოდ ერთი ფინალი შეიძლება ჰქონდეს. შედეგის ჩაწერა გამოცდის დღიდან შეიძლება. ჩაბარების ზღვარია მაქსიმუმის 50%.

- **ჩვეულებრივი გამოცდა**: თუ ვერ ჩააბარა, დაიგეგმება გადაბარება და შედეგი იმავე გამოცდის ახალ მცდელობად ჩაიწერება. სულ 3 მცდელობაა, ითვლება საუკეთესო. გადაბარება წინა მცდელობაზე გვიან დღეს უნდა იყოს.
- **ფინალური გამოცდა**: თუ ვერ ჩააბარა, სტუდენტი **ჩარჩა ფინალში**. სემესტრი და წელი მისთვის ღია რჩება, სანამ გადაბარებას არ ჩააბარებს. 3 წარუმატებელი მცდელობის შემდეგ სემესტრი თავიდან უნდა გაიაროს.

### სემესტრები, GPA და წლის ბოლო

სასწავლო წელი იწყება 1 სექტემბერს. I სემესტრი: 1 სექტემბერი - 31 იანვარი. II სემესტრი: 1 თებერვალი - 31 აგვისტო.

| რა | როგორ ითვლება |
|---|---|
| აქტივობა % | სემესტრის ქულების ჯამი, სადაც 100 ქულა = 100% (არც 100%-ზე მეტი, არც 0%-ზე ნაკლები) |
| გამოცდები % | გამოცდების საუკეთესო მცდელობების საშუალო, ფინალი ორმაგად ითვლება |
| ჯამი % | 60% გამოცდები + 40% აქტივობა. სანამ გამოცდა არ შეფასებულა, ჯამი მხოლოდ აქტივობაა და სემესტრი „წინასწარია“ |
| სემესტრის GPA | ჯამი % / 20, ანუ 100% = 5.00 |
| ასო | A 90+, B 80+, C 70+, D 60+, E 50+, F 50-ზე ნაკლები |
| წლის GPA | იმ წლის სემესტრების GPA-ების საშუალო |
| კუმულაციური GPA | ყველა სემესტრის საშუალო |

**წლის ბოლოს (31 აგვისტოს შემდეგ) რა ყვება:**

- სტუდენტი გადადის მომდევნო წელზე, თუ ყველა ფინალი ჩაბარებულია და წლის GPA სულ მცირე 2.50-ია. ადმინი `Academic` -> `Semesters and GPA` -> `Close an academic year` ხურავს წელს: წლის GPA-ს ასო ჩაიწერება სტუდენტის შეფასებად (სტუდენტის პროფილში), წლის შედეგი ინახება `years.txt`-ში.
- თუ სტუდენტი ფინალში ჩარჩა ან ფინალი არ ჩაუბარებია, წელი მისთვის არ იხურება, შეფასება არ იცვლება და გააგრძელებს მხოლოდ გადაბარების ჩაბარების შემდეგ. წლის ხელახლა დახურვა ასეთ სტუდენტს დაამუშავებს, როცა გადაბარებას ჩააბარებს.
- თუ წლის GPA 2.50-ზე დაბალია, სტუდენტი არ გადაჰყავთ, მაგრამ ისტორია რჩება.
- ახალ სემესტრში სემესტრის ქულები და რეიტინგი 0-დან იწყება. მთელი დროის ქულები, ისტორია, სტიპენდია და ძველი GPA-ები რჩება.

ძველი ხელით დაწერილი შეფასება (`Update grade`) და report card ცალკე რჩება და ახალ გამოთვლილ GPA-ზე არ არის დამოკიდებული, გარდა წლის დახურვისა, რომელიც გადაყვანილი სტუდენტის შეფასებას განაახლებს.

წლის დახურვის სანახავად ადმინმა `Finance` -> `Move the date forward (simulation)` გამოიყენოს და თარიღი 31 აგვისტოს შემდეგ გადაწიოს.

### შრიფტები

`Settings` -> `Fonts`: შრიფტის არჩევა ისევე მუშაობს, როგორც ფონის არჩევა: სიაში დააჭირე შრიფტს და ტერმინალი მაშინვე იცვლება; მიმდინარე შრიფტს ✓ აქვს. სიაში არის 20-ზე მეტი სტილი (სახალისო, რეტრო პიქსელური, ელეგანტური, საბეჭდი მანქანა, მომრგვალებული, ტექნო, თანამედროვე და ა.შ.) და Windows-ის შრიფტებიც (მაგ. Segoe Script დახრილი ხელნაწერისთვის, თუ კომპიუტერზე არის).

ქართულს ცალკე შრიფტი აქვს (`Choose the Georgian letters font`), რადგან შემოწმებისას ლათინური სტილის შრიფტებიდან არცერთს არ აქვს ქართული ასოები. ქართულისთვის არის DejaVu Sans Mono (მონოსპეისი, ცხრილებს სწორად ინარჩუნებს), Noto Sans Georgian, Noto Serif Georgian და Windows-ის Sylfaen, Segoe UI, Calibri. პროგრამა წერს ორივეს Windows Terminal-ის `settings.json`-ში ჩამონათვალად (`ძირითადი, ქართული, DejaVu Sans Mono`), ამიტომ ქართული და ცხრილის ხაზები ავტომატურად იღებს სწორ შრიფტს. ძველი პარამეტრების ასლი ინახება `settings.json.bak`-ში. `Bold text` ავლენს ან გამორთავს მუქ ტექსტს.

შეზღუდვები: ჩაწერა მუშაობს Windows Terminal-ში (სხვა ტერმინალებში გამოჩნდება ინსტრუქცია); მონოსპეისი არ არის Segoe Script, Segoe Print, Ink Free, Comic Sans MS და Gabriola, ამიტომ მათთან ცხრილის კიდეები შეიძლება გადაიწიოს; დახრილი (italic) მთელი ტერმინალისთვის Windows Terminal-ს არ აქვს, ამიტომ დახრილი სტილისთვის გამოიყენება Segoe Script. შრიფტის ფაილები (OFL/MIT) `Fonts/LICENSES.txt`-შია და მხოლოდ მაშინ კოპირდება შენს Windows მომხმარებლის საქაღალდეში, როცა შეარჩევ.
